LEGEND
  [OK]  file exists and is wired into the game (you hear it)
  [3b]  file exists, gets wired by the phase 3b prompt
  [--]  file exists but has no role / is in the wrong place
  +P1   MISSING — core sound you hear every match (make these first)
  +P2   MISSING — polish, makes the game feel better
  +P3   MISSING — later; the game system for it doesn't exist yet (don't record now)

FORMAT
  .wav  → short SFX and UI  (import: Mono, 44.1 kHz, Trim, Normalize, QOA, Loop OFF)
  .ogg  → music, ambient, voice  (import: Loop ON only for music and ambient beds)
  _01…  → variants of one sound (code picks one at random, never the same twice in a row)
          Hits/shots: 3–6 variants. Rare events: 1–2 are enough.

NOTES
  - Every new sound = 1 audio file + 1 SoundData .tres in data/sounds/ + (for a new
    kind of event) one hook in code. A new VARIANT of an existing sound = just drop the
    file into that SoundData's streams array — no code.
  - [3b] items start playing once the phase 3b prompt lands.
  - P3 sounds belong to the special-ability and sidekick systems (heroes_greek.md) —
    don't record them until those mechanics exist; the sound usually changes with the
    final design.
