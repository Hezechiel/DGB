FORMAT
  .wav  → short SFX and UI (import: Mono, 44.1 kHz, Trim, Normalize, QOA, Loop OFF)
  .ogg  → music, ambient, voice (import: Loop ON only for music and ambient beds)
  _01…  → variants of the same sound (the code picks one at random, never the same twice)
          Hits/shots: 3–6 variants. Rare events: 1–2 are enough.

NOTES
  - Each new sound = 1 audio file + 1 SoundData .tres in data/sounds/ + (for a new
    kind of event) one hook in the code. Adding a variant to an existing sound is just a
    new file in the SoundData's streams array — no code.
  - [3b] items start playing once the phase 3b prompt lands.
  - P3 sounds are tied to the special-ability and sidekick systems (heroes_greek.md) —
    don't record them until those mechanics exist; the sound usually changes with the final design.
